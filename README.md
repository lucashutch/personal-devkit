# my-scratchpad

Config and workflow scratchpad for Opencode.

## Included

- `opencode/` — Opencode agents, commands, and config
- `dotfiles/` — synced local terminal/editor configs

## Dotfiles

- `dotfiles/starship.toml`
- `dotfiles/ghostty/config`
- `dotfiles/ghostty/themes/vscode-dark`

## Notes

- `.vscode/`, `.ruff_cache/`, and other local caches are ignored via `.gitignore`

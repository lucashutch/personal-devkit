# Repo Map
Purpose: Personal, repo-managed OpenCode/Claude configuration, shell dotfiles, and installer/linking utilities.
Stack: TypeScript/TSX OpenCode plugins, JSON configuration, Python 3.11+, Bash

## Layout
- `opencode/v1/{home,work,test}/` — complete account-specific OpenCode V1 configs.
- `agentic_common/skills/` — the single copy of every skill, linked into Claude Code and all OpenCode profiles.
- `opencode/v1/shared/` — V1 agents, commands, plugins, TUI config, and plugin support data shared by all profiles.
- `opencode/v1/shared/plugins/herdr-agent-state.js` — official Herdr OpenCode integration shared by every V1 profile.
- `opencode/v2/{home,work,test}/` — profile-specific V2 global configs.
- `opencode/v2/shared/` — V2 CLI settings and agents linked into every V2 profile.
- `claude/` — Claude Code settings, agents, commands, themes, and statusline.
- `herdr/` — Herdr configuration.
- `dotfiles/` — Bash snippets, Ghostty configuration, and Starship theme.
- `scripts/` — Python installers/linker plus TypeScript schema maintenance utility.
- `links.yaml` — declarative source-to-destination mappings consumed by the linker.

## Entry points
- `scripts/install.py` — installs the toolkit's supported command-line tools.
- `scripts/link-config.py` — validates and applies `links.yaml`, then runs repository-specific OpenCode setup actions.
- `opencode/v1/shared/plugins/*.ts` — auto-loaded OpenCode V1 plugin modules.
- `opencode/v1/{home,work,test}/opencode.json` — profile-specific V1 global configs.
- `opencode/v2/{home,work,test}/opencode.json` — V2 profile-specific global configs.

## Commands
- Install tools: `scripts/install.py --help`
- Link config: `scripts/link-config.py --help`
- Install Python dependencies: `uv sync` (or run scripts ad hoc with `uv run scripts/link-config.py`)
- Python syntax check: `python3 -m compileall -q scripts`
- Tests: `uv run pytest`
- Lint: `uv run ruff check scripts`

## Conventions & gotchas
- Edit repository sources, never linked files under `~/.config/opencode*` or `~/.claude`.
- V1 and V2 profiles use isolated XDG roots. V2 wrappers are `o2h`, `o2w`, and `o2t`; service endpoints are configured locally, not committed.
- `opencode/v1/shared/plugins/slim-schemas.json` is generated by `scripts/update-slim-schemas.ts`, not hand-edited.
- Skills live once in `agentic_common/skills/` and must stay platform-neutral: never name a host-specific tool (`bash` vs `shell`, `question` vs `AskUserQuestion`), because the same file is loaded by Claude Code, V1, and V2. Agents are platform-specific and stay under `claude/agents/` and `opencode/v*/shared/agents/`.
- The worktree currently contains an in-progress migration from legacy `opencode/` paths into `opencode/v1/shared/`; preserve those user changes.

# Repo Map
Purpose: Personal, repo-managed OpenCode/Claude configuration, shell dotfiles, and installer/linking utilities.
Stack: TypeScript/TSX OpenCode plugins, JSON configuration, Python 3.11+, Bash

## Layout
- `opencode/v1/{home,work,test}/` — complete account-specific OpenCode V1 configs.
- `opencode/v1/shared/` — V1 agents, commands, skills, plugins, TUI config, and plugin support data shared by all profiles.
- `opencode/v2/` — minimal native V2 config, intentionally separate from V1 profiles.
- `claude/` — Claude Code settings, agents, commands, skills, themes, and statusline.
- `dotfiles/` — Bash snippets, Ghostty configuration, and Starship theme.
- `scripts/` — Python installers/linker plus TypeScript schema maintenance utility.

## Entry points
- `scripts/install.py` — installs the toolkit's supported command-line tools.
- `scripts/link-config.py` — symlinks repo sources into OpenCode V1/V2, Claude, and dotfile target locations.
- `opencode/v1/shared/plugins/*.ts` — auto-loaded OpenCode V1 plugin modules.
- `opencode/v1/{home,work,test}/opencode.json` — profile-specific V1 global configs.
- `opencode/v2/opencode.json` — native V2 global config.

## Commands
- Install tools: `scripts/install.py --help`
- Link config: `scripts/link-config.py --help`
- Python syntax check: `python3 -m compileall -q scripts`
- Tests/lint/build: no repository-wide manifest or CI commands are defined.

## Conventions & gotchas
- Edit repository sources, never linked files under `~/.config/opencode*` or `~/.claude`.
- V1 shared entries are linked into three isolated XDG config/data profiles; V2 has one global namespace.
- `opencode/v1/shared/plugins/slim-schemas.json` is generated by `scripts/update-slim-schemas.ts`, not hand-edited.
- The worktree currently contains an in-progress migration from legacy `opencode/` paths into `opencode/v1/shared/`; preserve those user changes.

---
description: Plan, implement, and ship a feature or fix on a branch with a draft PR
---

Run this pipeline:

1. **Understand** — `gh issue view` for a URL/number, else `question` to clarify.
2. **Branch** — derive a kebab-case name, create it, switch to it. Ask if remote exists.
3. **Plan** — route to @planner for `plan.md`.
4. **Implement** — run the Director wave loop. Commit after each milestone.
5. **Ship** — push. `gh pr create --draft` with title/body from the issue.
